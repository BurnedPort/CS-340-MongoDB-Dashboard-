CS 340 Portfolio Reflection

I write programs that are maintainable, readable, and adaptable by separating concerns and organizing code into reusable components. A key example of this was the CRUD Python module I developed in Project One and reused in Project Two. Instead of embedding database queries directly into the dashboard, I created a separate module to handle all database interactions. This made the code easier to read and maintain, since each part of the application had a clear responsibility. It also made debugging more efficient because issues could be isolated to either the database layer or the dashboard layer. Another advantage was adaptability, if the database schema or queries change, I only need to update the CRUD module rather than modifying multiple parts of the application. In the future, this module could be reused in other projects such as web applications, APIs, or cybersecurity tools that require structured data access and logging.

When approaching a problem as a computer scientist, I break it down into smaller components and focus on how each part interacts within the system. For this project, I started by understanding Grazioso Salvare’s requirements and identifying the necessary data operations needed to support the dashboard. I then designed queries and data structures that would efficiently retrieve and filter the required information. This approach differed from earlier assignments because it required integrating multiple technologies, MongoDB, Python, and a dashboard interface, rather than solving isolated problems. It felt more like real-world development. In the future, I would continue using this approach by focusing on modular design, efficient querying, and scalability when creating databases to meet client needs.

Computer scientists design systems that transform raw data into meaningful and actionable information. This matters because organizations depend on accurate and efficient data processing to make informed decisions. In this project, the dashboard I developed helps Grazioso Salvare quickly identify animals that meet specific rescue criteria without manually searching through large datasets. This improves efficiency, reduces manual effort, and enables better decision-making. Overall, this type of solution helps organizations operate more effectively by turning complex data into accessible and useful insights.
